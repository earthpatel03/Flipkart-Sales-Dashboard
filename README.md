# Flipkart-Sales-Dashboard
The Flipkart Sales Dashboard is a Power BI-based project that analyzes e-commerce sales data to provide insights into product performance, customer preferences, and overall business growth. It uses Python for data preprocessing and Power BI for creating interactive visualizations such as charts and KPIs.

The dashboard highlights key metrics like total revenue, total orders, and average order value, helping businesses understand their performance. It also allows users to analyze category-wise sales, top products, and the impact of discounts and ratings on customer behavior.

Overall, this project demonstrates how data visualization can support better decision-making in e-commerce. It helps businesses identify trends, improve strategies, and can be further enhanced with predictive analytics and real-time data integration.
